Цель лабораторной работы
Изучить базовые типы и конструкции языка Python: ввод-вывод, целые числа,
строки, списки, словари, кортежи и множества; научиться решать типовые
задачи обработки данных и реализовать диалоговое меню.

Теория (для отчёта, уложиться в 4 страницы)

1. Переменные и типы
В Python тип привязан к значению, а не к имени переменной. Основные типы
лабораторной: int (целое), float (вещественное), str (строка), bool,
list, tuple, dict, set. Функции type() и isinstance() показывают тип.

2. Ввод и вывод
input() читает строку с клавиатуры. Чтобы получить число, пишут
n = int(input()). print() выводит значения. f-строка позволяет вставить
выражение внутрь текста: f"сумма = {s}".

3. Ветвления и циклы
if / elif / else выбирают ветку по условию. Операции сравнения: == != < >
<= >=; логические: and or not.
for x in последовательность перебирает элементы. range(a, b) даёт целые
от a до b-1. while условие: повторяет блок, пока условие истинно.
break выходит из цикла, continue переходит к следующей итерации.

4. Числа и цифры
Последняя цифра: n % 10. Отбросить её: n // 10. Так в цикле while можно
разобрать любое натуральное число. Чётность: n % 2 == 0.
Простое число больше 1 и не делится ни на одно целое от 2 до квадратного
корня из числа. Делители ищут перебором d от 1 до n с проверкой n % d == 0.

5. Строки
Строка — неизменяемая последовательность символов. Индекс s[0], срез
s[1:4], разворот s[::-1]. Методы: split, lower, upper, swapcase, isalpha,
isdigit, islower, isupper, count, replace. ord(ch) даёт код Unicode,
chr(code) — символ. Гласные удобно хранить во множестве и проверять
ch.lower() in vowels. Палиндром: очищенная строка равна своему развороту.

6. Списки
Список изменяем: append, pop, remove, sort. Индексация с нуля.
Генератор [x for x in a if условие] строит новый список.
min, max, sum, count, index — частые функции лабораторной.
Срез a[i:j] копирует участок. Чтобы не портить исходные данные, считают
по копии или сначала собирают ответ, потом меняют список.

7. Словари
Словарь хранит пары ключ: значение. Ключ уникален и хешируем (строка,
число, кортеж). d[key] = value записывает, d.get(key, 0) читает и не
падает, если ключа нет. items() даёт пары. dict(zip(keys, values))
собирает словарь из двух списков. Сортировка по значению:
sorted(d.items(), key=lambda kv: kv[1]).

8. Кортежи и множества
Кортеж (tuple) похож на список, но его нельзя менять. Если нужна
сортировка, создают новый: tuple(sorted(t)).
Множество (set) хранит уникальные элементы. Операции: пересечение &,
объединение |, разность -.

9. Меню программы
Типовая схема: вечный цикл while True, вывод пунктов, choice = input(),
ветка if/elif или словарь функций. Данные магазина удобно хранить как
{название: [описание, цена, количество]}. Покупка уменьшает остаток и
накапливает сумму. Отдельный пункт завершает программу.

10. Оформление кода
Имена функций и переменных — латиницей, понятные. Отступ — 4 пробела.
Комментарии объясняют зачем, а не что видно из кода.
