Цель лабораторной работы
Научиться оформлять решение в виде функций, различать типы аргументов
при помощи isinstance, обрабатывать исключительные ситуации блоком
try/except/finally и работать с двумерными списками (матрицами).

Теория (для отчёта, уложиться в 4 страницы)

1. Функция
Функция — именованный блок кода. Объявление:
def имя(аргументы):
    тело
    return результат
return отдаёт значение вызывающему коду. Если return нет, функция
возвращает None. Аргументы бывают позиционные и со значением по
умолчанию: def f(a, b=0).

2. Область видимости
Переменные внутри функции локальны. Чтобы изменить внешнюю переменную,
нужен nonlocal или global; в лабораторной лучше возвращать результат,
а не полагаться на global.

3. Проверка типа
isinstance(x, int) — целое, isinstance(x, str) — строка,
isinstance(x, list), tuple, dict, set. Несколько типов сразу:
isinstance(x, (int, float)). Так одна функция может по-разному обработать
кортеж, список, число и строку — это ядро второго задания ЛР2.

4. Типовые задачи на функции
Палиндром: сравнить очищенную строку с разворотом.
Простое число: проверка делителей до квадратного корня.
Анаграммы: отсортированные списки букв совпадают.
Надёжный пароль: длина, есть заглавная, есть цифра (или строчная —
смотреть формулировку).
Вклад под проценты: каждый год сумма *= 1.1, цикл по годам.
НОД: алгоритм Евклида. НОК: a * b // НОД(a, b).
Факториал: произведение 1..n. Фибоначчи: два предыдущих члена.

5. Исключения
Ошибка во время выполнения — исключение. Если её не поймать, программа
остановится. Блок:
try:
    опасный код
except ТипОшибки:
    обработка
finally:
    код, который выполнится всегда
Частые типы: ValueError (int("abc")), ZeroDivisionError (деление на 0),
IndexError (неверный индекс), KeyError (нет ключа в словаре),
TypeError (неверная операция с типом).
except Exception ловит почти всё — для отладки можно, в отчёте лучше
указывать конкретный тип. У except есть объект ошибки: except ValueError as e.

finally нужен, чтобы закрыть файл, вернуть ресурс или напечатать
завершающее сообщение даже если внутри try произошла ошибка.

6. Матрица
Матрица n×m — список из n строк, каждая строка — список из m элементов.
Элемент: a[i][j], i — строка, j — столбец, нумерация с нуля.
Главная диагональ: i == j. Выше диагонали: i < j. Ниже: i > j.
Сумма строки: sum(a[i]). Сумма столбца j: sum(a[i][j] for i in range(n)).
Поменять столбцы i и j: в каждой строке row[i], row[j] = row[j], row[i].
Симметрия: a[i][j] == a[j][i] для всех i, j (квадратная матрица).
Шахматная заливка: если (i + j) чётно — ".", иначе "*".

Чтение с клавиатуры:
n, m = map(int, input().split())
a = [list(map(int, input().split())) for _ in range(n)]

7. Требования лабораторной
Каждое задание оформить функцией (или несколькими). Ввод и арифметику
обернуть в try/except. В finally показать, что обработка завершена.
Для задания с разными типами сделать отдельные проверки и вызвать
функцию на примерах каждого типа.
