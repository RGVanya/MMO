Цель лабораторной работы
Изучить объектно-ориентированное программирование в Python: класс,
экземпляр, конструктор, наследование, переопределение методов,
инкапсуляцию и три вида методов (экземпляра, класса, статический).

Теория (для отчёта, уложиться в 4 страницы)

1. Класс и объект
Класс — чертёж. Объект (экземпляр) — конкретная вещь по этому чертежу.
class Car:
    def __init__(self, name):
        self.name = name
self — ссылка на текущий объект. __init__ вызывается при создании:
car = Car("Solaris"). Атрибут self.name принадлежит этому объекту.

2. Методы экземпляра
Обычный метод всегда принимает self первым параметром. Он читает и
меняет поля конкретного объекта: self.speed, self.color.

3. Статические поля и приватность
Поле, записанное в теле класса (не в self), общее для всех объектов:
class EngAlphabet:
    __letters_num = 26
Одно подчёркивание _price — договорённость «не трогать снаружи»
(защищённый атрибут). Два подчёркивания __letters_num включают искажение
имени (приватный атрибут). Геттеры и сеттеры — методы доступа к полям.

4. Наследование
class TownCar(Car): означает: TownCar умеет всё, что умеет Car, плюс своё.
super().__init__(...) вызывает конструктор родителя, чтобы не копировать код.
Переопределение: в потомке пишут метод с тем же именем — при вызове
используется версия потомка. Пример: show_speed у TownCar дополнительно
проверяет лимит 60. Полиморфизм: список из TownCar, SportCar, WorkCar
можно обойти одним циклом и вызвать go()/show_speed() у каждого.

5. Три вида методов (задание 4 есть почти во всех вариантах)

Метод экземпляра — нужен объект:
    def describe(self): ...

Статический метод — обычная функция внутри класса, self не нужен:
    @staticmethod
    def minutes_to_read(pages): ...
Вызов: Class.minutes_to_read(100) или obj.minutes_to_read(100).

Метод класса — первым аргументом идёт cls (сам класс):
    @classmethod
    def created_count(cls): ...
    @classmethod
    def from_string(cls, raw): return cls(...)
Через cls можно создавать объекты альтернативным конструктором и читать
общие счётчики класса.

6. Типовые сюжеты лабораторной
Калькулятор: методы add, sub, mul, div и метод ввода.
Фигуры: Triangle/Square/Circle считают площадь и периметр, наследники
переопределяют area().
Car / TownCar / SportCar / WorkCar / PoliceCar: движение и лимит скорости.
Stationery / Pen / Pencil / Handle: общий draw(), у каждого своё сообщение.
Worker / Position: защищённый словарь дохода, полное имя и зарплата.
House / SmallHouse / Human: скидка и покупка, если хватает денег.
Alphabet / EngAlphabet: родительский алфавит и уточнение для английского.

7. Запись в файл
with open("data.txt", "w", encoding="utf-8") as f:
    f.write(text)
Конструкция with сама закроет файл, даже если будет ошибка.

8. Как проверять работу
Создать несколько объектов, вызвать методы, напечатать поля, показать
разницу переопределённых методов у родителя и потомка. Для задания 4
обязательно вызвать все три вида методов и подписать в выводе, какой это вид.
